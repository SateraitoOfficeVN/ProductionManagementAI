# ja

Japanese PDFs of the documents under `../en/`, in `pdf/` at the same relative paths (for example `pdf/010_basic-design/001/001_BD_production-order-create-edit.pdf`). Each is rendered from a Japanese translation of the English Markdown, which is the source of truth; the translation is not kept here, and the page footer names the English revision it was translated from. See `ai/rules/documentation.md` and RFC 0008. Documents that predate the rule get their PDFs the next time they are edited, so some documents have none yet.

`presentations/ai-harness-overview.pdf` is the Japanese edition of the ai/ harness deck in `../en/presentations/`, with the same slides and the text translated.
