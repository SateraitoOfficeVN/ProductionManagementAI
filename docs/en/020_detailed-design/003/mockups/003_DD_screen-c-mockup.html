Production dashboard

Rendered states for Screen C with its Japanese UI (WI-005), in the app's existing look — the same Tailwind gray palette and system font as the Screen A and Screen B mockups. Static rendering: it fixes layout, state coverage and the treatment of tiles, groups and charts. Behaviour — loading, Retry, the table disclosure — is specified in 003_DD-SPD. Nothing on the dashboard is a link; navigation lives in the shared header's navbar (DEC-006, DEC-016). Version 2 of this mockup added the navbar, the health indicator and chart maximize from the mockup review (DEC-016–DEC-018); version 3 adds the icons (DEC-023).

Icons are Lucide 1.47.0 (ISC licence), inlined here from lucide-static; the app uses lucide-react at the same version (DEC-023). Charts are inline SVG with no library (DEC-010). In the app each chart is role="img" with a summary naming every bar's value; the printed values and the table carry the same numbers.
