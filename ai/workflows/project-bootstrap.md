# Bootstrap the project

Read [policies](../policies.md) and [project context](../project.md). Select applicable [skills](../skills/README.md).

1. Confirm open technology decisions and demo scope.
2. Draft the bootstrap plan, including skeleton, local environment and CI checks.
3. After approval, create the shared harness/application setup in bounded steps.
4. Verify actual commands and update project.md.
5. Record remaining gaps before handing off to feature delivery.

Use [templates](../templates/README.md) for durable state. Exit when the approved scope and its checks are complete; otherwise record the blocker and next action.
