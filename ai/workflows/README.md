# workflows

Choose project-bootstrap for initial setup, feature-delivery for a feature, bug-fix for a defect, or harness-improvement for shared guidance changes. Work on a feature or defect whose work item has ended (done, merged or closed out) starts a new work item; never reopen the closed one (RFC 0015).
