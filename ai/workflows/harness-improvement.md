# Improve the harness

Read [policies](../policies.md) and [project context](../project.md). Select applicable [skills](../skills/README.md).

1. Record an observed failure or project change; identify the affected guidance.
2. Propose the smallest useful change and its expected behavior.
3. Evaluate with relevant cases from ai/evaluations.
4. Record limitations and submit the change for review before shared adoption.
5. Retain a rollback path through version control; never silently relax gates to pass an evaluation.

Use [templates](../templates/README.md) for durable state. Exit when the approved scope and its checks are complete; otherwise record the blocker and next action.
