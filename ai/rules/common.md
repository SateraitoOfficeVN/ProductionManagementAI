# common rules

- Read the current work item and preserve approved scope.
- Never restart or reopen a work item that has ended (done, merged or closed out); start a new work item with the next free `WI-###` number for any follow-up, even on the same feature, link the closed one from its brief, and leave the closed work item's records and approved designs unedited (RFC 0015).
- Use stable requirement, screen and test IDs; link artifacts instead of duplicating them.
- Record unresolved decisions explicitly. Follow explicit user decisions over proposals.
- Keep changes focused, preserve unrelated work and record real verification evidence.
